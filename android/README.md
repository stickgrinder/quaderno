# Quaderno for Android

Not started. Planned after the GNOME app's version 1.0.

It will be a Gradle project in this folder, using the shared vault library through `crates/quaderno-vault-ffi` (Kotlin bindings generated with uniffi). It keeps its own translations, derived from the default labels described in `vault-spec/format.md` §6.2. It must follow the same hard rules as every Quaderno client (`AGENTS.md`).
