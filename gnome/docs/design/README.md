# GNOME design artboards

Export each artboard of the Quaderno design canvas as PNG into this folder (canvas Share › Export), named after the artboard: `Main.png`, `Dream.png`, `FirstRun.png`, `Unlock.png`, `Notes.png`, `PrefsWriting.png`, `PrefsLists.png`, `PrefsGeneral.png`, `Icon.png`, and for later versions `Insights.png`, `QuickCapture.png`.

They are visual references for `../ui-spec.md`. Where a picture and the spec disagree, the spec wins.
