# quaderno-vault

The shared Rust library that reads and writes Quaderno vaults: encryption, migrations, typed data access, snapshots, validation and (from 1.1) merging. No GTK, no Android code. Implements `vault-spec/format.md`, embedding `vault-spec/migrations/*.sql`.
